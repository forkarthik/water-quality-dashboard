GitHub Pages Public Client Security Rule

GitHub Pages hosts static files visible to the entire public internet. If you put tenant administrator passwords or private device provisioning tokens inside client-side JS, they will be leaked.

  • Recommended Architecture: ESP32 → ThingsBoard → Serverless Proxy (Cloudflare Worker or Vercel Edge Function with hidden API token) → GitHub Pages.
  • Native ThingsBoard Alternative: Use ThingsBoard's "Make Dashboard Public" feature to generate a read-only Public Token, or query public read endpoints.
  • Browser Sandbox: Custom values configured in this modal are stored exclusively in your local browser's localStorage and are never committed to git.
